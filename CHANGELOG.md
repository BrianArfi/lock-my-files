## [0.1.0] - 2026-09-09
<!-- source: GitHub release v0.1.0 (BrianArfi/lock-my-files), published 2026-09-09 -->

### Added
- First public build. Android only (Android 7 or later, arm64-v8a and armeabi-v7a).
- Vaults with separate passwords, and 12 recovery words per vault.
- Per-file passwords that the vault password cannot open.
- Encrypted file names, not only file contents.
- No internet permission: the app cannot open a network connection.
